Bio & FocusHaqqımda və Fokus Sahələrim

I am a Junior Penetration Tester with practical experience in vulnerability assessments, system security, and penetration testing across Linux and Windows environments. I have a strong focus on web application security, network penetration, and Active Directory exploitation, backed by hands-on expertise with tools like Burp Suite, Nessus, Cobalt Strike, and Havoc C2.

Holding certifications such as eJPT, CRTA, and WEB-RTA, I am able to identify security weaknesses, adapt to new challenges, and continuously improve my skills in real-world environments.

Şəbəkə, sistem və tətbiq təhlükəsizliyi sahəsində praktiki təcrübəyə malik Junior Penetration Tester-əm. Linux və Windows mühitlərində zəifliklərin qiymətləndirilməsi, sistem təhlükəsizliyi və penetration testing üzrə iş təcrübəm var. Xüsusi olaraq veb tətbiq təhlükəsizliyi, şəbəkə hücumları və Active Directory istismarına fokuslanmışam — bu sahələrdə Burp Suite, Nessus, Cobalt Strike və Havoc C2 kimi alətlərlə praktiki iş bacarığım var.

eJPT, CRTA və WEB-RTA sertifikatlarına sahib olaraq, təhlükəsizlik boşluqlarını aşkarlamaq, yeni çağırışlara uyğunlaşmaq və real mühitlərdə bacarıqlarımı davamlı inkişaf etdirmək qabiliyyətinə malikəm.
